# 实验报告：实现 `sys_trace` 系统调用功能

## 实验目标

本次实验的目标是实现一个新的系统调用 `sys_trace`，用于追踪当前任务的系统调用历史信息。根据传入的 `trace_request` 参数的不同，`sys_trace` 将执行以下操作：
1. 读取当前任务的 ID。
2. 写入数据到任务 ID 地址。
3. 查询当前任务某个系统调用的调用次数。

## 功能要求

- **`trace_request == 0`**: 读取当前任务的 ID 地址处一个字节的无符号整数值。`id` 应被视作 *const u8，忽略 `data` 参数，返回读取的值。
- **`trace_request == 1`**: 将 `data`（最低位的一个字节）写入 `id` 地址处。`id` 应被视作 *mut u8，返回值为 0。
- **`trace_request == 2`**: 查询当前任务执行编号为 `id` 的系统调用次数，并返回该次数。

## 实现步骤

### 1. 更新 `TaskControlBlock` 结构

为了跟踪每个任务的系统调用次数，在 `TaskControlBlock` 结构中新增了一个名为 `syscall_count` 的字段，这是一个固定大小的数组，长度为 `MAX_SYSCALL_NUM`，用于记录每个系统调用的执行次数。

### 2. `sys_trace` 系统调用实现  
sys_trace 系统调用根据 trace_request 的值执行不同的操作：

读取任务 ID（trace_request == 0）

当 trace_request == 0 时，我们通过传入的 id 参数（指向任务 ID 的指针）读取该任务的 ID。通过指针解引用操作读取并返回该字节值。
写入数据到任务 ID 地址（trace_request == 1）

当 trace_request == 1 时，我们将 data（最低位的一个字节）写入指定的任务 ID 地址。
查询系统调用次数（trace_request == 2）

当 trace_request == 2 时，我们调用 get_syscall_count 函数来查询当前任务执行某个系统调用的次数，并返回该次数。在查询之前，我们会先增加该系统调用的调用次数。
### 3. 统计系统调用次数
每个系统调用执行时，我们会在其对应的 TaskControlBlock 中的 syscall_count 数组中，增加该系统调用的调用次数。为了实现这一点，我们需要确保每次系统调用被调用时，都会触发 syscall_count 的更新。
